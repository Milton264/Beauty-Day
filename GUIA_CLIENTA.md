# Cómo actualizar Beauty Day

Abre el enlace del panel e ingresa tu correo autorizado y contraseña. Cada administrador tiene su propia cuenta. Si recibiste autorización para registrarte, usa **Crear acceso administrativo**, confirma tu correo y luego inicia sesión.

1. En **General** edita textos, horario, teléfonos, redes y dirección.
2. En **Servicios** cambia tratamientos, precios y duración. **Categorías** organiza el catálogo; **Equipo** permite editar profesionales y especialidades.
3. **Promociones**, **Bonos** y **Combos** contienen las otras opciones del negocio.
4. Para cambiar una fotografía, selecciona JPG, PNG o WebP. El panel intenta optimizarla; después pulsa **Guardar cambios**.
5. Guarda y recarga la página pública para revisar el resultado. Los cambios se consultan directamente desde la base de datos.

Si otra persona guardó mientras editabas, el panel pide recargar para evitar sobrescribir su trabajo. Las fotos del catálogo son públicas. Completa el responsable y correo de privacidad en **Privacidad**.

## Acceso a precios

Revisa manualmente los seguimientos en Instagram, TikTok y Facebook, comunica el importe y confirma la cita por WhatsApp. En **Acceso a precios** marca las cuatro comprobaciones, genera un código de 24 horas y copia el mensaje para enviarlo al cliente. Para retirarlo, usa **Retirar un acceso**. Las páginas abiertas vuelven a comprobar el código cada minuto.

## Administradores

En **Administradores** autoriza el correo de cada persona antes de que cree su cuenta. Puedes desactivar accesos ajenos; no puedes desactivar tu propia cuenta desde esa sesión. Desactivar el correo retira el permiso en la siguiente petición, aunque la persona siga con la sesión abierta.

Puedes recuperar tu contraseña desde el inicio de sesión cuando el correo del proyecto esté configurado. No necesitas editar código ni abrir GitHub para actualizar el contenido.
